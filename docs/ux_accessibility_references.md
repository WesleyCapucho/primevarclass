# PrimeVarClass - UX, acessibilidade e linguagem clara

Este documento resume as referencias usadas para evoluir a interface publica e o manual do PrimeVarClass.

## Principios adotados

- Acessibilidade desde o inicio, com alvo pratico em WCAG 2.2 nivel AA.
- Linguagem do usuario, nao linguagem interna do desenvolvimento.
- Status visivel para execucoes longas, jobs, validacao, sync e erros.
- Ajuda consistente: manual, glossario, feedback e referencias sempre acessiveis no topo.
- Interface bilingue PT-BR/EN com atributo `lang` atualizado.
- Documentacao em camadas: leitura rapida para iniciantes e detalhes para usuarios senior.
- Conteudo cientifico honesto: separar software pronto, evidencia computacional e confirmacao experimental.

## Checklist de interface

- Existe uma rota clara para o usuario iniciar.
- O idioma pode ser alterado no primeiro viewport.
- Links de manual, glossario e feedback sao visiveis sem busca.
- Botoes descrevem a acao, nao apenas a tecnologia.
- Mensagens de erro explicam o que fazer em seguida.
- Nao ha dependencia exclusiva de cor para comunicar estado.
- Campos importantes tem labels visiveis.
- Conteudo longo e dividido por headings.
- Saidas dinamicas importantes usam status textual.
- A documentacao explica limites cientificos antes de claims fortes.

## Checklist de manual

- Uma mensagem principal por secao.
- Termos tecnicos aparecem com definicao ou link para glossario.
- Exemplos usam formatos reais, como HGVS e CSV.
- A linguagem evita jargoes quando uma palavra simples resolve.
- Os limites da plataforma sao declarados explicitamente.
- O fluxo atende iniciantes e usuarios senior sem duplicar documentacao.
